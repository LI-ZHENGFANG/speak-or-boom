Speak or Boom
开发者与版权所有者：LI ZHENGFANG

一、准备
Windows 电脑、Chrome 浏览器、麦克风和耳机。下载完整 ZIP 并解压；不要只打开压缩包中的 index.html。第一次使用需要安装 CPython 3.8，安装来源为 Python 官方网站：https://www.python.org/downloads/release/python-3810/ 。保留较新的 Python 也可以，启动器会明确选择 Python 3.8。

二、启动
1. 解压后双击 START.cmd。保留打开的服务窗口。
2. 浏览器会自动打开 http://localhost:8000/ 。如未自动打开，把这个地址输入 Chrome。
3. 选一个场景，首次建议选 5 MIN，点击 START。Chrome 提示使用麦克风时选择允许。
4. 开始前可先做免费麦克风测试与校准，再试听英语声音。听对方说完；出现 YOUR LINE 时，照着屏幕字幕读。软件检测持续发声，并在符合条件后进入下一轮。
5. 暂停使用 PAUSE，继续使用 RESUME。暂停页可以“听这句的示范发音”，听示范时练习保持暂停，准备好再继续。切换到其他应用或标签页也会自动暂停。结束后回到服务窗口按 Ctrl+C。
6. 想练对方的角色，可在开始前勾选“互换角色”。两边台词及对应配音会一起交换。

三、练习规则
六种场景：咖啡店、机场、酒店、求职面试、餐厅和原创职场故事 Ship It! 第一集。时长可选 5、10、60 分钟。当前是写好的对话跟读，不是自由聊天。
轮到你时，持续沉默 3 秒出现提醒，5 秒再次提示，8 秒进入倒计时，12 秒结束本轮。对方播放语音及暂停期间，不进行沉默倒计时。
60 分钟模式按各场景编写顺序播放，完成一遍后按顺序重复台词持续练习，不是一小时完全不重复的剧情。
字幕逐词高亮供跟读参考，目前并非精确的发音时间对齐。发声检测也不是专业的单词或发音评分；语音识别不可用时，音量检测仍可工作。

四、虚拟记录
初始余额为 ¥10.00，每轮虚拟锁定 ¥1.00。完成后返还 ¥0.90；失败扣除该轮虚拟押金。所有数字均用于练习，没有真实支付，也不用充值。
记录保存在当前浏览器的本地存储中。同一个 localhost 地址刷新后会保留；更换浏览器、地址或清除浏览器数据不会同步这些记录。
Reset Demo Data 会在确认后恢复 ¥10.00，并清零统计。

五、常见问题
对方说得太快：首页和暂停画面均可调节“对方语速”，默认 0.75，可选 0.60–1.10，1.00 为原音速度。调整会自动保存，从下一次播放开始生效。默认使用完整剧本的美式英语配音，手机与电脑播放同一套声音；也可主动选择设备的系统英语声音。
对方没有声音：先点首页英语试听。播放报错时练习会自动暂停，不会启动你的沉默倒计时。如果系统英语播放正常、网页报 synthesis-failed，可彻底关闭并重新打开 Chrome 再试。
没有麦克风反应：检查 Windows 输入设备与 Chrome 站点的麦克风权限，确认没有被静音。读句子时声音应清晰可闻，尽量在安静环境中使用。
不要使用音箱播放对方声音：它可能漏进麦克风。请戴耳机。
出现 MIC BLOCKED：允许站点使用麦克风，刷新页面再开始。
START.cmd 提示缺少 Python 3.8：安装 Python 3.8 和 Python Launcher 后重新启动。已有其他版本不用卸载。
8000 端口被占用：在该文件夹中打开终端，运行 py -3.8 start_local.py --port 8001，再访问 http://localhost:8001/ 。不同端口的练习记录分别保存。
微信下载不方便：把下载链接复制到电脑浏览器下载。这个作品是电脑网页工具，不需要安装手机 App 或微信小程序。

六、作品文件
START.cmd / start_local.py：本地启动。
index.html / style.css / app.js：界面与练习逻辑。
coffee-script.js / scenarios：场景台词。请保留整个文件夹。
voice-manifest.js / recorded-audio.js / audio：全量两方配音及播放。共 804 轮、1,608 条 MP3。配音文件必须随完整文件夹一起保留；在线使用无需安装配音模型。配音为合成语音，不是电影原声。
